# SemanticClothingRecommender

A semantic fashion search and recommendation system powered by **SentenceTransformers**, **FAISS**, and an optional **LLM** for re-ranking and personalised styling advice.

---

## 🏗 System Architecture

```
User Query (text or image)
        ↓
Text & Image Encoder   (SentenceTransformers all-MiniLM-L6-v2)
        ↓
Vector Database        (FAISS — cosine similarity)
        ↓
Top-K Similar Clothes
        ↓
LLM Re-ranking & Styling Advice   (OpenAI GPT — optional)
        ↓
Final Recommendations
```

## 🚀 Quick Start

### 1 · Clone & create virtual environment

```bash
git clone https://github.com/mya404/SemanticClothingRecommender.git
cd SemanticClothingRecommender
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2 · Download the dataset

Download **Myntra Fashion Product Dataset** from Kaggle:  
<https://www.kaggle.com/datasets/hiteshsuthar101/myntra-fashion-product-dataset>

Place `Fashion Dataset.csv` inside the `data/` folder:

```
data/Fashion Dataset.csv
```

### 3 · Build the FAISS index

Open and run all cells in `preprocessing.ipynb`.  
This will:
- Clean and preprocess the dataset
- Generate semantic embeddings for every product
- Build and save the FAISS index to `index/`

### 4 · (Optional) Configure the LLM

Create a `.env` file in the project root:

```ini
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini
```

Without this the system still works — FAISS ordering is used and a
rule-based styling tip is shown instead of an LLM-generated one.

### 5 · Launch the app

```bash
streamlit run app.py
```

Open <http://localhost:8501> in your browser.

## 🔧 Configuration

All tuneable parameters live in `config.py` and can be overridden via
environment variables:

| Variable | Default | Description |
|---|---|---|
| `TEXT_EMBEDDING_MODEL` | `sentence-transformers/all-MiniLM-L6-v2` | Embedding model |
| `TOP_K_RETRIEVAL` | `20` | Candidates retrieved from FAISS |
| `TOP_N_FINAL` | `5` | Items shown to the user |
| `OPENAI_API_KEY` | *(empty)* | Enables LLM re-ranking |
| `OPENAI_MODEL` | `gpt-4o-mini` | OpenAI model for styling advice |

## 🗂 Dataset

Real product data from **Myntra** (Indian e-commerce) with the following fields:

| Column | Description |
|---|---|
| `p_id` | Product ID |
| `name` | Product name |
| `price` | Price (INR) |
| `colour` | Colour |
| `brand` | Brand name |
| `img` | Thumbnail URL |
| `ratingCount` | Number of ratings |
| `avg_rating` | Average rating |
| `description` | Product description |
| `p_attributes` | Additional attributes (dict) |

🔗 <https://www.kaggle.com/datasets/hiteshsuthar101/myntra-fashion-product-dataset>
